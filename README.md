# Pixel Life v10 — แผนวัน เหตุการณ์ และครอบครัว (Web / Godot 4.7)

เกมจำลองชีวิตพิกเซลแนวนอน **960×540** ที่เดินสำรวจจริงได้ทั้งเมือง
เริ่มชีวิตตอน **อายุ 6 ขวบ** ไปโรงเรียน ทำงาน หาเงิน ออกกำลังกาย กลับบ้านนอน
พร้อมระบบอาชีพ การเงิน สุขภาพ ครอบครัว เพื่อนบ้าน 4 ฤดู และแกนเล่นใหม่ของ v10
— **แผนวัน 3 ช่วงเวลา เหตุการณ์สุ่ม 16 แท็บเหลือ 5 กลุ่ม** ต่อยอดจาก
**ฟาร์มหลังบ้าน ตกปลา จับแมลง ร้านของตัวเอง ชมรม ความสำเร็จ บ้านอัปเกรด ปาร์ตี้ ชื่อเสียง ข่าวลือ เดท แต่งงาน ฮันนีมูน ออกทริปครอบครัว และการถ่ายทอดลักษณะลูกจากพ่อแม่**

![town_street](screenshots/town_street.png)

- **ไม่มีไฟล์รูปภาพในเกม**: เมือง ตัวละคร เฟอร์นิเจอร์ และสภาพอากาศ วาดจากโค้ดทั้งหมด
- **เล่นผ่านเว็บ**: ส่งออกด้วย preset Web ไปยัง `docs/` แล้วเสิร์ฟผ่าน GitHub Pages (เซฟเกมอยู่ในเบราว์เซอร์)
- **แผนวัน v10**: เลือก 1 กิจกรรมต่อช่วง เช้า/บ่าย/เย็น แล้วทำตามแผนให้ครบ — สำเร็จได้โบนัส ผิดแผนเสียเครียดและเงิน
- **เหตุการณ์สุ่มรายวัน**: เจอเรื่องไม่คาดคิดพร้อมทางเลือก 2–3 ทาง ผลลัพธ์ต่างกันจริง
- **ความกดดันใหม่**: พลังงานหมดเร็วขึ้น ค่าครองชีพสูงขึ้น เครียดถึง 90 จะหมดไฟ และขาดงาน 5 ครั้งถูกเลิกจ้าง
- **หน้าจอเหลือ 5 กลุ่ม**: วันนี้ / ตัวละคร / งาน-เงิน / บ้าน / ชีวิต พร้อมบรรทัด "ควรทำอะไรต่อ"
- **ครอบครัว v9**: เดท มีคนรัก และวางแผนมีลูกได้โดยไม่จำเป็นต้องแต่งงานก่อน • ลูกสืบทอดสีผิว สีผม และทรงผมจากทั้งสองฝ่าย
- **เดินได้จริง**: 17 โซนเชื่อมกันด้วยถนน ประตู และรถเมล์ (มีสวนหลังบ้านแห่งใหม่)
- **NPC 28 คน** มีทรงผม/ชุด/เครื่องประดับเฉพาะตัว เดินตามตารางเวลา และมีชื่อลอยเหนือหัว
- **เควสต์รายสัปดาห์** 3 ภารกิจจาก NPC/ใบประกาศ • ตัวนับรีเซ็ตทุกสัปดาห์ • ใบประกาศทองแดง/เงิน/ทอง
- **เป้าหมายชีวิต 3 สาย** — ครอบครัวอบอุ่น / อาชีพมั่นคง / ตำนานเมือง พร้อมคะแนน 0–100 และฉากจบหลายแบบ
- **ทักษะชีวิต 7 ด้าน** — สื่อสาร / วิชาการ / งานฝีมือ / ทำอาหาร / ศิลปะ / กีฬา / เทคโนโลยี
- **บ้านอบอุ่น** — เฟอร์นิเจอร์ 10 ชิ้น แมวน้อย ของสะสมตามฤดู 12 ชนิด อัปเกรดบ้าน 4 ระดับ และปาร์ตี้ที่บ้าน
- **ฟาร์ม 6 แปลง** ปลูก–รดน้ำ–เก็บเกี่ยว–ขาย พร้อมพืช 5 ชนิด และโบนัสกรรมพันสายดิน
- **ตกปลา/จับแมลง** ปลา 6 ชนิด แมลง 5 ชนิด มีมินิเกมและของหายาก
- **ธุรกิจร้านของตัวเอง** เปิดร้าน เติมสต็อก ขายรายวัน และอัปเกรดได้ 4 ระดับ
- **ชมรม 6 ชมรม** + เรียนพิเศษ + ชีวิตสังคมและเพื่อนสนิท
- **ความสำเร็จ 19 รายการ** พร้อมรางวัลเงิน ชื่อเสียง 0–100 และข่าวลือรายวัน
- **เทศกาล 4 ครั้ง/ปี** พร้อมมินิเกม บูธเกม และรางวัล
- **ชุด 14 แบบ** (11 ชุดปกติ + 3 ผ้าห่อตัวแรกเกิด) และ **ทรงผม 8 แบบ / สีผม 8 สี / สีผิว 5 เฉด**
- **พื้นฐานครอบครัว** — เลือกครอบครัวเริ่มต้น 1 จาก 5 แบบ แล้วได้รับผลติดตัวตลอดชีวิต
- **ความรักครบวงจร** — เดท มีคนรัก แต่งงานได้ และวางแผนมีลูกโดยไม่ต้องแต่งก่อน
- **1 วันจริง ≈ 4.5–6 นาที**, 28 วันในเกม = 1 ปี
- **ภาษาไทยทั้งเกม** ใช้ฟอนต์ระบบ (Segoe UI / Noto Sans Thai / Leelawadee UI / Tahoma)
- เซฟอัตโนมัติทุกแอ็กชัน (ไฟล์เซฟเวอร์ชัน 10 — โหลดเซฟ v5–v9 เดิมได้)

## เครื่องมือพัฒนา

ไฟล์ที่ใช้เล่นสำหรับผู้เล่นคือเว็บบิลด์ใน `docs/`; การรัน Godot โดยตรงด้านล่างมีไว้ตรวจและพัฒนาภายในเท่านั้น

ต้องใช้ Godot 4.7.2 สำหรับแก้ไข/ทดสอบโปรเจกต์

- **รันเกมเพื่อ debug:** ดับเบิลคลิก `run-game.bat` (ตัวเล่นสำหรับผู้เล่นอยู่ในเว็บบิลด์)
- **เปิด editor:** ดับเบิลคลิก `run-editor.bat`
- หรือใช้คำสั่ง `godot --editor --path .` จากโฟลเดอร์โปรเจกต์

```powershell
godot --path .
```

## เว็บบิลด์

โปรเจกต์มี Export Preset ชื่อ **Web** และส่งออกไว้ที่ `docs/` แล้ว
เว็บบิลด์ฝังฟอนต์ไทย/อังกฤษ/ตัวเลข/สัญลักษณ์/อีโมจิไว้ในเกม ใช้ได้กับ static hosting โดยไม่ต้องตั้ง COOP/COEP headers

ส่งออกใหม่ด้วย Godot 4.7.2:

```powershell
godot --headless --path . --export-release "Web" "docs/index.html"
```

ทดสอบในเครื่องโดยเสิร์ฟโฟลเดอร์ `docs/` ผ่านเว็บเซิร์ฟเวอร์ (อย่าเปิด `index.html` ด้วย `file://`):

```powershell
cd docs
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000/` ในเบราว์เซอร์ เว็บบิลด์นี้รองรับการโฮสต์บน static hosting เช่น itch.io, GitHub Pages หรือ Cloudflare Pages

## วิธีเล่น

| ทำอะไร | วิธี |
|---|---|
| เดิน | `WASD` / ลูกศร / จอยสติ๊กซ้ายล่าง / ลากนิ้ว |
| ใช้ของ / คุย / เข้าประตู | เดินเข้าใกล้แล้วกด `E` หรือ `Enter` หรือปุ่ม **E ใช้** มุมขวาล่าง |

| เดินข้ามโซน | เดินออกขอบซ้าย/ขวาของแผนที่ หรือใช้รถเมล์ |

> สีของตัวละครเปลี่ยนตามชุดที่สวม และตัวจะโตขึ้นเมื่ออายุมากขึ้น

### แผนวัน (แกนหลัก v10)

ทุกเช้าเกมจะเปิดแท็บ **วันนี้** ให้วางแผน 3 ช่วง:

| ช่วง | เวลา | ตัวอย่างกิจกรรม |
|---|---|---|
| เช้า | 06:00–12:00 | ทำงาน / ไปโรงเรียน / อ่านหนังสือ / ออกกำลังกาย / พักผ่อน |
| บ่าย | 12:00–18:00 | ทำงาน / ดูแลสวน / พบผู้คน / พักผ่อน |
| เย็น | 18:00–24:00 | พบผู้คน / พักผ่อน / ดูแลสวน |

- ทำกิจกรรมตรงกับแผนภายในช่วงนั้น = **แผนสำเร็จ** (+฿60, ความสุข +4, เครียด -3)
- เลยเวลาแต่ยังไม่ได้ทำ = **ผิดแผน** (เครียด +6, ความสุข -5, เงิน -50; งาน/เรียนโดนเพิ่ม)
- ทำครบทั้ง 3 ช่วง = **โบนัส +฿250** และสะสมสตรีคข้ามวัน
- ปล่อยช่วงว่างได้ ไม่โดนโทษ แต่ก็ไม่ได้โบนัส
- ทุกวันมีโอกาส **30%** เจอเหตุการณ์สุ่มให้เลือกตอบ (สูงสุดวันละ 1 เรื่อง)

พลังชีวิตมีจำกัด: พลังงานลดลงทุกชั่วโมง ทำได้ราว 3 กิจกรรมใหญ่ต่อวัน และถ้าเครียดถึง 90 จะ **หมดไฟ** ทำให้วันรุ่งขึ้นเริ่มด้วยพลังงาน 65

## ทิศทางศิลปะและ UI ของ v8

**โลก cozy pixel อบอุ่น**

- ต้นไม้หนาแน่นหลายชั้น ซ้อนเงาและใบไม้คนละเฉด
- บ้านอิฐ/ไม้ หลังคาสีอุ่น กันสาด ระเบียง กระถางต้นไม้ และรั้วไม้
- แสงไฟตะเกียง หน้าต่างบ้าน และโคมไฟถนนยามเย็น
- เงา Soft shadow ใต้ตัวละคร เฟอร์นิเจอร์ และต้นไม้
- สีเปลี่ยนตาม 4 ฤดู — ใบไม้ผลิชมพูอ่อน, ร้อนเขียวสด, ใบไม้ร่วงส้มทอง, หนาวหิมะขาว

**UI ไม้/กระดาษอบอุ่น**

- กรอบไม้สีน้ำตาลเข้ม + แผงกระดาษสีครีม
- ปุ่มไม้ ปุ่มทองเหลือง และแถบความคืบหน้าแบบกระดาษ
- ฟอนต์ไทยนุ่ม อ่านง่ายทั้งจอคอมและมือถือ
- หน้าสร้างตัวละครแบบสองคอลัมน์ พร้อมตัวอย่างตัวละครสด ๆ

## วงจรวันและปฏิทิน

| ระบบ | ค่า |
|---|---|
| เวลาในเกม | **4 นาทีในเกม = 1 วินาทีจริง** |
| 1 วัน | 06:00–24:00 (ช่วงตื่น ≈ 4.5 นาทีจริง · เต็มวัน 1,440 นาที = 6 นาทีจริง) |
| ตื่นนอนเริ่มวัน | 06:00 |
| โรงเรียน | จันทร์–ศุกร์ **08:00–15:00** |
| ทำงาน | จันทร์–ศุกร์ **08:00–17:00** |
| เข้านอน | หลัง **18:00** ถึงก่อน 06:00 |
| นาฬิกาปลุก | 06:00 / 07:00 / 08:00 |
| หมดวัน | 24:00 ยังไม่นอน = **สลบ** มีบทลงโทษ |
| 1 ฤดู | 7 วัน |
| 1 ปี | **28 วัน** (4 ฤดู × 7 วัน) |
| วันเกิด | วันที่ 1 ของฤดูใบไม้ผลิ → อายุ +1 |
| บิล/ค่าใช้จ่าย | ทุก 28 วัน |

## เริ่มชีวิต — ผ้าห่อตัวและกรรมพันจากพ่อแม่

หน้า **สร้างชีวิตใหม่** ให้เลือก 9 อย่าง พร้อมพรีวิวตัวละครสด ๆ:

- **ชื่อ** — สุ่มใหม่ได้
- **เพศ** — ชาย / หญิง
- **ฐานะครอบครัว** — ยากจน / ปานกลาง / ร่ำรวย
- **ผ้าห่อตัวแรกเกิด** — ฟ้า / ชมพู / เขียว (3 แบบ)
- **ครอบครัว** — 5 แบบ ซึ่งกำหนด **กรรมพัน** ติดตัว
- **เป้าหมายชีวิต** — ครอบครัวอบอุ่น / อาชีพมั่นคง / ตำนานเมือง (v8)
- **สีผิว** — 5 เฉดอบอุ่น
- **สีผม** — 8 สี
- **ทรงผม** — 8 ทรง (สั้น / หยิก / ยาว / มวย / หางม้า / หน้าม้า / หวีเสย ฯลฯ)

ตัวละครพรีวิวจะเปลี่ยนสีผิว สีผม ทรงผม และชุดตามที่เลือกทันที
ตัวละครเป็นสไตล์ **cozy chibi** หัวโตเล็กน้อย มีคอ ไหล่ แขน มือ ขา รองเท้า และเงา
หันซ้าย–ขวา–หลังได้ พร้อมท่าเดิน ยืน นั่ง และสีหน้าตามสถานะ (ดีใจ / เหนื่อย / เครียด / เศร้า / ป่วย / เขิน)

## ฟาร์มหลังบ้านและงานอดิเรก (v7)

### สวนหลังบ้าน

| **ตกปลา** | ที่ท่าเรือ • วันละ 5 ครั้ง • ใช้พลังงาน 8 • มินิเกมคะแนน ≥ 40 = ได้ปลา |
| **จับแมลง** | ที่จุดจับแมลง • วันละ 5 ครั้ง • ใช้พลังงาน 6 • มินิเกมคะแนน ≥ 40 = ได้แมลง |

### ชมรมและเรียนพิเศษ

## ชื่อเสียง ข่าวลือ และความสำเร็จ (v7)

- **ชื่อเสียง 0–100** ขึ้นจากเทศกาล งานอดิเรก ร้านค้า ปาร์ตี้ และการอัปเกรดบ้าน

- **ข่าวลือรายวัน** มีโอกาสปรากฏทุกวัน (สูงขึ้นตามชื่อเสียง) ดูได้ที่ **สรุป → รางวัล**
- **ความสำเร็จ 19 รายการ** เช่น เก็บเกี่ยวครั้งแรก นักตกปลาแห่งเมือง เจ้าของร้าน บ้านในฝัน คู่ชีวิต ฮันนีมูนหวาน คนดังแห่งเมือง
  - ปลดล็อกอัตโนมัติเมื่อถึงเงื่อนไข • รับรางวัลเงินได้ที่แผงรางวัล • ได้ชื่อเสียง +2 ต่อการรับรางวัล

## เควสต์ เป้าหมายชีวิต และฉากจบ (v8)

### ภารกิจรายสัปดาห์

เปิดได้ที่ **สรุป → ภารกิจ** — ทุกสัปดาห์จะสุ่มภารกิจ **3 อย่าง** จาก 14 แบบ
โดยแต่ละสัปดาห์จะได้ประเภทภารกิจไม่ซ้ำกัน และตัวนับจะรีเซ็ตเมื่อขึ้นสัปดาห์ใหม่

| ประเภท | ตัวอย่างภารกิจ | เป้าหมาย |
|---|---|---|
| เก็บเกี่ยว | เก็บผักให้ครัว / สวนขาจร | 3 หรือ 6 ครั้ง |
| ตกปลา | มื้อปลาเย็นนี้ / นักตกปลาหน้าฝน | 2 หรือ 4 ตัว |
| จับแมลง | ตามล่าผีเสื้อ | 3 ตัว |
| เรียน | ห้องเรียนขยัน / สัปดาห์แห่งความรู้ | 2 หรือ 4 วัน |
| ทำงาน | กะพิเศษ / คนขยันประจำสัปดาห์ | 2 หรือ 4 กะ |
| คุยกับผู้คน | เพื่อนบ้านทักทาย / ผีเสื้อสังคม | 4 หรือ 7 ครั้ง |
| ธุรกิจ | เปิดร้านสักวัน | 1 วัน |
| ชมรม | กิจกรรมชมรม | 2 ครั้ง |
| ของสะสม | ของสะสมตามฤดู | 2 ชิ้น |

- ทำครบเป้าหมายแล้วกด **รับรางวัล** ในแผงภารกิจ → ได้เงินตามภารกิจ + ชื่อเสียง +3
- ภารกิจที่ทำสำเร็จสะสมจะปลดล็อก **ใบประกาศ** อัตโนมัติ:
  - ครบ **5 ภารกิจ** → ใบประกาศทองแดง +฿800
  - ครบ **12 ภารกิจ** → ใบประกาศเงิน +฿2,000
  - ครบ **24 ภารกิจ** → ใบประกาศทอง +฿5,000
- ความคืบหน้านับจากการกระทำจริงในเมือง เช่น เก็บเกี่ยวที่สวน ตกปลาที่ท่าเรือ ไปโรงเรียน ทำงาน คุย NPC เปิดร้าน ทำกิจกรรมชมรม และเก็บของสะสม

### เป้าหมายชีวิต 3 สาย

เลือกได้ตอน **สร้างชีวิตใหม่** — คะแนนเป้าหมาย 0–100 คิดจากสถานะจริง และแบ่งเป็น 5 ระดับ:
เริ่มต้นเส้นทาง → เส้นทางเริ่มชัด → ก้าวหน้าอย่างมั่นคง → ใกล้ถึงความฝัน → สมบูรณ์แบบ

| สาย | สิ่งที่ทำให้คะแนนขึ้น | ตัวอย่าง |
|---|---|---|
| **ครอบครัวอบอุ่น** 🏡 | ความรักพ่อแม่/คู่ชีวิต การแต่งงาน จำนวนลูก ความสุข ความอบอุ่นบ้าน แมว และสังคม | ดูแลคนที่รักและสร้างบ้านที่มีเสียงหัวเราะ |
| **อาชีพมั่นคง** 💼 | การศึกษา ระดับงาน ประสิทธิภาพ เงินสด+เงินออม ธุรกิจ และทักษะเฉลี่ย | สร้างเนื้อสร้างตัวและมีร้านเป็นของตัวเอง |
| **ตำนานเมือง** 🌟 | ชื่อเสียง ความสำเร็จ ของสะสม เทศกาล ภารกิจสะสม ปลา/แมลง และสังคม | เป็นที่รู้จักและสร้างเรื่องเล่าให้เมืองจดจำ |

### ฉากจบหลายแบบ

เมื่อชีวิตจบ หน้าจอ **ชีวิตจบแล้ว** จะแสดงฉากจบตามสายเป้าหมายและคะแนนที่ทำได้
พร้อมอันดับ **S / A / B / C** — แต่ละสายมี 3 ฉากจบ (เริ่มต้น / ก้าวหน้า / สมบูรณ์) รวม **9 แบบ**
เช่น *บ้านหลังใหญ่แห่งความรัก*, *เจ้าของตำนานนักสร้าง*, *ตำนานที่ไม่มีวันจาง*
พร้อมสรุปภารกิจที่ทำสำเร็จ ใบประกาศ อายุ วันที่ใช้ชีวิต และเงินคงเหลือ

## เดท แต่งงาน ฮันนีมูน และครอบครัว (v7)

- **เดท** กับ NPC ที่เดทได้ 14 คน เมื่ออายุ 18+ และความสัมพันธ์ถึงระดับที่กำหนด (฿300)
- **แต่งงาน** ซื้อแหวน ฿5,000 • ต้องมีความรัก ≥ 70 • โอกาสสำเร็จ 50% + ความรัก/300 + เสน่ห์ชุด/300
- **ฮันนีมูน** ฿6,000 หลังแต่งงาน • ความรัก +20 • ความสุข +18 • เครียด -20
- **มีลูก** ฿3,000 • อายุไม่เกิน 45 • มีได้สูงสุด 3 คน • ปลดล็อกความสำเร็จ **คุณพ่อคุณแม่**
- **ออกทริปครอบครัว** ฿700/สัปดาห์ • ความสุข +10 • เครียด -8 • ความรักของคู่รัก +6 (ถ้ามี)

ดูทุกอย่างได้ที่ **สรุป → ความรัก** และ **สรุป → ชีวิต**

## พ่อแม่และครอบครัว

พ่อ **สมชาย** และแม่ **สมหญิง** มีตารางเวลาเดินไปทำงาน/กลับบ้านจริง

| คน | ที่อยู่ตามเวลา |
|---|---|
| พ่อ | บ้าน 06:00–08:30 → ออฟฟิศ 08:30–17:00 → บ้าน 17:00–22:00 |
| แม่ | บ้าน 06:00–09:00 → โรงพยาบาล 09:00–15:00 → บ้าน 15:00–22:00 |

เดินไปคุยกับพ่อหรือแม่ที่บ้านแล้วกด `E` จะเปิดบทสนทนา:

- **คุยด้วย** — ความรักพ่อแม่ +2 (วันละครั้งต่อคน)
- **ขอเงินใช้** — ได้เงินตามฐานะครอบครัว (สัปดาห์ละครั้ง)
- **กินข้าวเย็นด้วยกัน** — ช่วง 18:00–21:00 ที่บ้าน ความอิ่ม +30 ความรัก +3

ความรักพ่อแม่มีผลกับมรดกตอนอายุ 50+ และถูกใช้เป็นเงื่อนไขบทสนทนาหลายอย่าง
ครอบครัวที่เลือกตอนเกิดยังให้โบนัสเริ่มต้นและกรรมพันติดตัวตามตารางด้านบน

## ไอเดียต่อยอด

1. **เพิ่มโซน/ร้าน** — เพิ่มใน `TownData.ZONES` แล้ววาดใน `TownArt.gd`
2. **เพิ่ม NPC** — เพิ่มใน `TownData.NPCS` พร้อม `spots`, `hair_style`, `style`, `accessory`
3. **เพิ่มมินิเกม** — เพิ่มใน `Minigames.gd` แล้วเรียกจาก `TownHud.start_minigame()`
4. **เพิ่มเทศกาล** — เพิ่มใน `GameState.FESTIVALS` แล้วใช้มินิเกมที่มีอยู่หรือเพิ่มใหม่
5. **เพิ่มเฟอร์นิเจอร์** — เพิ่มใน `FURNITURE` + `TownData.FURNITURE_SLOTS` + วาดใน `draw_furniture()`
6. **เพิ่มของสะสม** — เพิ่มใน `COLLECTIBLES` พร้อมฤดูและโซน
7. **เหตุการณ์เฉพาะวัย** — เพิ่มใน `LifeEvents.gd` (ปฐมนิเทศ ใบขับขี่ งานแต่ง ฯลฯ)
8. **เสียง** — ใส่ SFX เดิน/กดปุ่ม/ฝนตก ด้วย `AudioStreamPlayer`
9. **ภาพพิกเซลจริง** — เปลี่ยนจากวาดโค้ดเป็น `.png` จาก Aseprite ได้โดยไม่กระทบกติกา
