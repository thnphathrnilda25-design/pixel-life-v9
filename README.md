# Pixel Life — ชีวิตพิกเซล

เกมจำลองชีวิตพิกเซลภาษาไทย สร้างด้วย **Canvas 2D และ JavaScript ล้วน** ในบรรยากาศเมืองเล็กอบอุ่น มีทั้งงานประจำ ฟาร์ม สัตว์เลี้ยง โรงเรียน และเวทมนตร์ ไม่ต้องติดตั้ง dependency หรือ build ก่อนเล่น

## เล่นเกม

- เปิด `index.html` ในเบราว์เซอร์ หรือใช้ static web server
- GitHub Pages ใช้ไฟล์ใน `docs/` (ตั้งค่า Pages ให้ deploy จาก branch `main` → `/docs`)
- เซฟอัตโนมัติไว้ใน `localStorage` ของเบราว์เซอร์และอุปกรณ์นั้น

## วิธีควบคุม

- เดินด้วย `WASD` หรือปุ่มลูกศร; แตะ/คลิกตำแหน่งบนฉากเพื่อเดินไปหา
- กด `E` หรือปุ่ม **ใช้** เพื่อคุยและโต้ตอบกับสิ่งของ
- เปิด **สมุดชีวิต** เพื่อดูแผนรายวัน ตัวละคร งาน บ้าน สัตว์เลี้ยง เวทมนตร์ และข้อมูลชีวิต
- กด **จบวัน** เพื่อพักและเริ่มวันถัดไป

## ในเกมมีอะไรบ้าง

- เมืองหลายย่านและระบบเดินทางด้วยรถเมล์/รถไฟใต้ดิน
- ตัวละครปรับแต่งได้: สีผิว สีผม ทรงผม เสื้อผ้า และเครื่องประดับ
- โรงเรียน มหาวิทยาลัย การสอบ ทักษะ และอาชีพ
- ปลูกพืช เลี้ยงไก่ วัว แกะ และแพะ พร้อมเก็บ/ขายผลผลิต
- รับเลี้ยงสัตว์เลี้ยงที่เดินตามตัวละคร
- เวทมนตร์ คาถา คริสตัล กิลด์ และบอส
- ความสัมพันธ์ ครอบครัว บ้าน ธุรกิจ ภารกิจ เทศกาล และความสำเร็จ
- งานภาพพิกเซลอบอุ่น: แสงตามเวลา เงานุ่ม ฉากเมือง/ชนบท และแอนิเมชันตัวละคร

## พัฒนาและทดสอบ

ไม่มี build step: แก้ไฟล์ใน `js/` และ `css/` แล้วเปิด `index.html` ใหม่ได้ทันที

```sh
node tests/smoke.js
```

โครงสร้างหลัก:

- `index.html` — หน้าหลักและ canvas
- `js/data.js` — ข้อมูลเมือง ตัวละคร และไอเท็ม
- `js/state.js` — กติกาเกมและเซฟ
- `js/render.js` — ฉากและสไปรท์ Canvas 2D
- `js/ui.js` — เมนูและหน้าระบบต่าง ๆ
- `js/main.js` — อินพุตและลูปเกม
- `css/style.css` — ธีมและ responsive UI
- `docs/` — สำเนาเว็บสำหรับ GitHub Pages

เกมทำงานแบบ client-side ทั้งหมด ไม่มี backend, WebAssembly หรือไลบรารีภายนอก
