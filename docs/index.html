ชีวิตเล็ก ๆ ในเมืองใหญ่ — เล่นได้ในเบราว์เซอร์ ไม่ต้องโหลดเกมหนัก

เล่นอย่างไร

  1. วางแผนวัน — ทุกเช้าเลือกกิจกรรม 3 ช่วง (เช้า/บ่าย/เย็น) ทำตามแผนได้โบนัส ผิดแผนมีบทลงโทษ
  2. เดินสำรวจ — ใช้ WASD/ลูกศร/คลิก หรือปุ่มลูกศรบนจอ เดินเข้าใกล้ของแล้วกด E
  3. รักษาชีวิต — กินข้าว พักผ่อน ลดเครียด ทำงานหาเงิน จ่ายบิลทุก 28 วัน
  4. สร้างอนาคต — เรียน เก็บทักษะ สะสมของ เปิดร้าน มีครอบครัว
