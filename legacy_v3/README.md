# legacy_v3 — เก็บไว้เป็นประวัติ

โฟลเดอร์นี้เก็บโค้ดเวอร์ชัน v3 (ห้องเดียวแนวตั้ง 480×854) ที่ **ไม่ได้ถูกใช้ในเกม v4** แล้ว
เกมหลักตอนนี้คือ `scenes/Town.tscn` (เมืองเดินได้แนวนอน 960×540)

| ไฟล์ | คืออะไร |
|---|---|
| `Room.tscn` | ฉากห้องเดียวของ v3 |
| `Room.gd` | การเดิน/ชนเฟอร์นิเจอร์ในห้อง |
| `RoomArt.gd` | วาดห้องด้วยโค้ด |
| `Hud.gd` | HUD แนวตั้ง + เมนู v3 |
| `screenshots/` | ภาพหน้าจอ v3 (แนวตั้ง) |

> `scripts/Art.gd` และ `scripts/LifeEvents.gd` **ยังใช้อยู่ใน v4** จึงไม่ได้ย้ายมาที่นี่
> ถ้าต้องการรันฉาก v3 ให้เปิด `legacy_v3/Room.tscn` ใน editor โดยตรง
> (แต่ระบบเซฟปัจจุบันเป็น v4 แล้ว เกมจะเริ่มชีวิตใหม่)
